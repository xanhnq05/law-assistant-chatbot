# Chatbot hỗ trợ pháp luật

Đây là một dự án chatbot hỗ trợ người dùng tra cứu và hỏi đáp về các vấn đề pháp luật của nước Việt Nam. Dự án sử dụng Python và các mô hình AI để trả lời các câu hỏi liên quan đến luật, quy định và thông tin pháp lý một cách tự nhiên.

## Yêu cầu
- Python 3.10 trở lên
- Tài khoản và API key từ Groq

## Cài đặt
1. Clone dự án về máy.
2. Vào thư mục dự án.
3. Tạo môi trường ảo (khuyến nghị):
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```
4. Cài đặt các thư viện cần thiết:
   ```bash
   python -m pip install -r requirements.txt
   ```
5. Thêm file .env

## Chạy dự án
```bash
python main.py
```

Nếu bạn muốn, có thể mở rộng dự án bằng cách thêm các câu hỏi mẫu, cơ sở dữ liệu luật hoặc giao diện người dùng thân thiện hơn.
